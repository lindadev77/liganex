# ADR-0001: 项目名称

- **状态**：已采纳（2026-08-29）
- **决策人**：lindadev77

## 背景

需要为一套包含 MCP Server、开放平台、智能客服、Skill 生态的开源项目命名，用于求职作品集，目标是从零搭建并开源到 GitHub。

## 候选与取舍

| 候选 | 结果 |
|---|---|
| `liganex` | GitHub 用户名 404、npm 404、liganex.com/.io/.dev 全未注册，GitHub 同名仓库 total: 0 ✅ |
| `ligandkit` | 同样三方全空，但 `kit` 后缀略朴素 |
| `emporium` | GitHub 同名 3922 个，污染严重 ✗ |
| `tradeflow` | 773 个且全被量化交易项目占用 ✗ |

## 决策

采用 **Liganex** = ligand（配体，化学中连接大分子的小分子）+ nexus（枢纽）。

- 语义贴合：MCP 本质是"把 LLM 与工具/数据接起来"，与 ligand 的连接隐喻一致
- 命名保持通用，**不嵌入行业词**（避免垂直化名字锁死天花板）
- 业务场景作为落地**场景**，而非名称前缀

## 后果

- 子项目统一前缀 `liganex-`，总入口用裸名
- 文档站计划使用 `liganex.dev`
